# 可选依赖：多模态解析（图片 OCR / 语音转写）

#
# 安装：取消注释后 pip install -r requirements.txt
#
# 模型存放位置（仓库根 ai/models/）：
#   - OCR：rapidocr-onnxruntime 默认内置 ONNX 模型即可用；
#          如需离线固定版本，将 det.onnx / rec.onnx / cls.onnx 放到 ai/models/rapidocr/
#   - 语音：faster-whisper small 模型放在 ai/models/whisper/faster-whisper-small/
#          可用环境变量覆盖：MULTIMODAL_STT_MODEL_PATH / MULTIMODAL_OCR_MODEL_DIR
# ============================================================
